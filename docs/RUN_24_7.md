# 24/7 ongestoord draaien (VPS + systemd + persistentie + logs)

Doel: de bot draait **altijd door**, **herstart automatisch** bij een crash of
reboot, **onthoudt zijn posities** over herstarts heen, en je kunt **op elk moment
de logs bekijken** (in de terminal én in het dashboard).

## 1. Waar draaien

Niet op je werkstation (dat slaapt/herstart). Gebruik een **kleine, altijd-aan
Linux-VPS** — bv. Hetzner CX22 (~€4/mnd), DigitalOcean/Vultr (~$6), of Contabo.
Ubuntu/Debian. Voor testnet maakt de regio niet uit; voor later (echt geld) zit
Binance in AWS Tokio (ap-northeast-1) voor lagere latency.

## 2. Installeren op de VPS

```bash
sudo apt update && sudo apt install -y python3-venv python3-full git
git clone https://github.com/bryan-helsens/Bot.git ~/custom/Bot
cd ~/custom/Bot
git checkout claude/binance-trading-bot-build-bBmx6
python3 -m venv .venv && source .venv/bin/activate
pip install -e ".[api]"

cp .env.testnet.example .env          # vul je testnet-keys in
cp config/strategies.paper.example.yaml config/strategies.yaml
python scripts/test_testnet.py --order --paper   # preflight, moet groen zijn
```

## 3. Als auto-herstartende service (systemd)

Er is een kant-en-klare unit: `deploy/quantbot.service`. **Pas `User`,
`WorkingDirectory` en `ExecStart`-pad aan** naar jouw machine, dan:

```bash
sudo cp deploy/quantbot.service /etc/systemd/system/quantbot.service
sudo systemctl daemon-reload
sudo systemctl enable --now quantbot     # start nu + bij elke boot
sudo systemctl status quantbot           # draait het?
```

- **Start automatisch op bij boot** en **herstart vanzelf na een crash**
  (`Restart=always`). Je hoeft geen terminal open te houden.
- Stoppen/herstarten: `sudo systemctl stop|restart quantbot`.

## 4. State-persistentie (naadloos herstarten)

De bot bewaart cash, open posities en de equity-curve in **`data/state.json`** (de
`STATE_FILE` in `.env`/config). Bij een (her)start laadt hij dit terug en
reconcilieert met de beurs — dus een herstart verliest geen posities of historie.
Zet `STATE_FILE=` (leeg) om persistentie uit te zetten.

## 5. Logs bekijken — op elk moment

**In de terminal (volledige historie via journald):**
```bash
journalctl -u quantbot -f             # live meekijken
journalctl -u quantbot --since "1 hour ago"
journalctl -u quantbot -p warning     # alleen waarschuwingen/fouten
```

**In het dashboard:** onderaan zit een **"Logs"-paneel** dat de recente
gebeurtenissen live toont (gekleurd per niveau, auto-scroll). Dat leest de laatste
~1000 regels uit de draaiende bot via `GET /system/logs`.

> Het dashboard draait al mee in hetzelfde proces (`quantbot serve`) op poort 8000.
> Wil je het dashboard van buitenaf bekijken? Zet een reverse proxy (nginx) of een
> SSH-tunnel op (`ssh -L 8000:localhost:8000 user@vps`) en open dan de frontend.

## 6. Updaten naar nieuwe code

```bash
cd ~/custom/Bot
git pull
sudo systemctl restart quantbot       # herstart pakt de nieuwe code op
```
Dankzij de persistentie hervat hij naadloos met je bestaande posities/equity.

## Samengevat
- ✅ VPS + `systemctl enable` → draait 24/7, herstart bij boot en na crash.
- ✅ `data/state.json` → posities/equity overleven herstarts.
